# Slang语法文档
## 模块以及块机制
Slang使用模块以及块机制来组织代码,模块是可重用的代码块,块是模块中的代码块,模块也是块的一种   
块通过如下方法声明
```slang
public/private(默认public) static/unstatic(默认unstatic) async/sync(默认sync) name:块定义
```
块定义如下:   

| 块类型 | 块定义                                |
|--------|---------------------------------------|
| 模块   | module{块列表}                        |
| 类     | class (implements 接口名){块列表}     |
| 接口   | interface (implements 接口名){块列表} |
| 枚举   | enum{A,B,C,...}                       |
| 函数   | Type(param:Type,...){命令列表}        |
| 变量   | Type(=Expr);                          |
### 特殊行为
1. 同名模块默认合并
2. 类必须实现他实现接口和接口实现的接口的所有函数
## 表达式
1. 字面量:数字/字符串/true/false/null
2. 数组:[...Expr],Map:[...Key:Value]
3. 标识符:变量/函数/常量引用
4. 函数字面量:(参数名:类型,...)=>返回类型{命令列表}
5. 括号:(Expr)
### 运算符
| 分类 | 运算符 |
|------|--------|
| 后缀 | ++/--自增自减,.成员访问,[下标]索引,(实参)调用 |
| 前缀 | ++/--,!逻辑非,~按位取反,-负号,&取地址,*解引用,new创建 |
| 乘除模 | * / % |
| 加减 | + - |
| 移位 | << >> |
| 比较 | < > <= >= |
| 相等 | == != |
| 按位 | & ^ \| |
| 逻辑 | && \|\| |
| 三目 | 条件?Expr:Expr |
优先级从高到低:后缀>前缀>乘除模>加减>移位>比较>相等>按位>逻辑>三目
## 命令
基本命令以;结尾:
1. 变量声明:`var 名称:类型(=Expr);`
2. 赋值:`=` 及复合赋值 `+= -= *= /= %= &= |= ^= <<= >>=`
3. 调用:[await] Expr;
4. 返回:return [Expr]; / break; / continue; / throw Expr;
5. 自增自减:Expr++; Expr--;
6. 内联VM指令:vm "指令";
流程控制:
7. if(条件)命令 [else 命令]
8. while(条件)命令 / do 命令 while(条件);
9. for(初始化;条件;步进)命令,初始化必须是变量声明,步进为命令列表
10. foreach(变量:Expr)命令
11. switch(条件){case Expr=>命令列表... [default=>命令列表]}
12. try 命令 catch(变量:类型)命令 [finally 命令]
13. {命令列表} 代码块
## 类型
| 类型 | 写法 |
|------|------|
| 数字 | number |
| 字符串 | string |
| 布尔 | boolean |
| 空 | void |
| 数组 | T[] |
| Map | T{} |
| 指针 | T* |
| 函数 | (参数名:类型,...)=>返回类型 |
| 类/枚举 | 类型名(.嵌套类型)* |
类型修饰符可叠加,如number[][]为二维数组,string{}为字符串Map
